Neutronenstern

Kollabierter Sternkern · Der nächste ~400 Lichtjahre entfernt

Wie groß ist ein Neutronenstern?

Ein Neutronenstern hat einen Durchmesser von etwa 22,0 km.

In 3D erkunden: ein Neutronenstern

Wenn einem Stern, der viel schwerer als die Sonne ist, der Brennstoff ausgeht, stürzt sein Kern in etwa einer Sekunde zusammen, und der Rest explodiert als Supernova. Übrig bleibt ein Neutronenstern: etwa anderthalb Sonnenmassen, zusammengepresst in eine Kugel von der Größe einer Stadt, gehalten nur vom Druck dicht gepackter Neutronen.

Gut zu wissen

  • Ein Zuckerwürfel aus Neutronensternmaterie wöge etwa so viel wie der Mount Everest.
  • Seine Oberflächenschwerkraft ist etwa 200 Milliarden Mal so stark wie die der Erde; ein Fall aus einem Meter brächte einen auf ein Zehntel der Lichtgeschwindigkeit.
  • Viele schwenken Radiostrahlen herum wie Leuchttürme. Wir nennen sie Pulsare, und sie gehen so genau wie Atomuhren.
  • Nächstkleineres: Deimos · 12,4 km
  • Nächstgrößeres: Phobos · 22,2 km
